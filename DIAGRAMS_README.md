## 🎨 Draw.io Use Case Diagram

We have created a full-featured Use Case Diagram covering the **entire website** (Passenger, Driver, and Admin portals). It is saved at:
📂 **[RIDE_RESERVE_USE_CASE.drawio](file:///c:/Users/Shubhang%20R/Desktop/PROJECT_MONGO/RIDE_RESERVE_USE_CASE.drawio)**

### 🚀 How to open and edit the diagram:

#### Option A: Web Browser (Draw.io)
1. Go to [app.diagrams.net](https://app.diagrams.net/).
2. Select **Open Existing Diagram**.
3. Choose the `RIDE_RESERVE_USE_CASE.drawio` file from your workspace root.
4. You will see the entire diagram beautifully rendered with dark mode tech styling, clean actors, usecase bubbles, and connection lines, fully editable!

#### Option B: VS Code Extension
1. Install the **Draw.io Integration** extension by *Henning Dieterichs* in VS Code.
2. Simply click on the `RIDE_RESERVE_USE_CASE.drawio` file inside your explorer.
3. The diagram will open directly inside your editor for quick visual updates.
